# Aside 명령 모음 (검증된 문구)

> 실제 위키화에서 성공한 문구를 기준으로 함. `<sheet_url>`은 config.json의 sheet_id로 만든 주소
> 모든 명령은 `aside exec "<지시>" > <스크래치패드>/<파일>.txt 2>&1` 로 실행하고 timeout 600000ms
> 결과에서 본문을 꺼낼 때는 `scripts/extract_marked.py` 사용

## A1. 노트북 소스 목록 확인 (읽기 전용)
```
NotebookLM(https://notebooklm.google.com)에서 '<노트북명>' 라는 이름의 노트북을 찾아서 열고, 소스 목록에 있는 소스 제목을 모두 알려줘. 이름이 정확히 같은 노트북이 없으면 비슷한 이름의 노트북 목록을 알려줘. 아무것도 수정하거나 삭제하지 마. 결과는 <<<BEGIN>>>과 <<<END>>> 사이에 한 줄에 하나씩 적어줘.
```

## A2. 책별 추출 (P01)
- 노트북에 소스가 1개면 "선택되어 있는지 확인", 여러 개면 "그 소스 하나만 선택하고 나머지는 선택 해제" 문구 사용
- 프롬프트 본문은 볼트 `99_admin/prompts/P01_책별추출.md`의 ```text 블록을 그대로 넣음
  (`awk '/^```text/{f=1;next}/^```/{f=0}f' P01_책별추출.md`)
```
NotebookLM(https://notebooklm.google.com)에서 '<노트북명>' 노트북을 열어줘. 소스 '<소스 제목>' 하나만 선택(체크)하고 나머지 소스는 선택 해제해줘. 그다음 채팅창에 아래 '프롬프트:' 뒤의 내용을 줄바꿈 포함 그대로 입력하고 전송해줘. 답변 생성이 완전히 끝날 때까지 기다린 뒤, 답변 전문을 요약하거나 줄이지 말고 마크다운 그대로(표 포함) <<<BEGIN>>>과 <<<END>>> 사이에 출력해줘. 답변 하단의 복사 버튼을 쓰면 정확해. 노트북 설정, 소스, 기존 노트는 바꾸거나 삭제하지 마.

프롬프트:
<P01 본문>
```

## A3. 묶음 비교 (P02, 2권 이상)
```
NotebookLM '<노트북명>' 노트북에서 소스 <소스1>, <소스2>, … 만 선택하고 나머지는 선택 해제한 뒤, 채팅창에 아래 '프롬프트:' 뒤의 내용을 그대로 입력하고 전송해줘. 답변이 끝나면 전문을 줄이지 말고 마크다운 그대로 <<<BEGIN>>>과 <<<END>>> 사이에 출력해줘. 노트북 설정, 소스, 기존 노트는 바꾸거나 삭제하지 마.

프롬프트:
<P02 본문>
```

## A4. 시트 상태 기입 (행 확인 후 기입)
```
Google Sheet <sheet_url> 를 열어줘. <행>행이 A열 '<연번>', D열 '<도서명>' 인지 먼저 확인하고, 맞으면 H<행>에 '<상태>', I<행>에 '<노트북명>' 을 입력해줘. 다른 셀은 절대 바꾸지 말고, 행이 다른 책이면 아무것도 입력하지 말고 보고해줘. 마지막에 A, D, H, I열의 변경 전후 값을 알려줘.
```
- 여러 행이면 행마다 (행, 연번, 도서명)을 나열
- `검토완료` 처리 시: "H열이 '위키반영'인지 확인하고 맞으면 H만 '검토완료'로"

## A5. 시트 신규 행 추가 (`신규 확인`, 사용자 승인 후에만)
```
Google Sheet <URL> 의 마지막 데이터 행 아래에 다음 행들을 추가해줘. 기존 행은 절대 바꾸지 마. 각 행: A 연번(마지막 연번 다음부터), B 대분류 폴더, C 세부 폴더/시리즈, D 도서명, E 저자, F 파일 링크, G 폴더 링크, H·I 비움.
<표로 행 목록>
추가 후 새로 추가된 행 번호와 값을 보고해줘.
```
- F열 파일 링크: Drive 도구 `search_files`(title contains '<도서명>')로 파일 ID를 찾아 `https://drive.google.com/file/d/<ID>/view` 형식

## 실패 대응
| 증상 | 대응 |
|---|---|
| 표식 없음·본문 200자 미만 | 같은 명령 1회 재시도 → 실패 시 사용자에게 수동 붙여넣기(`01_inbox`) 요청 |
| 노트북을 못 찾음 | A1 결과의 비슷한 이름 목록을 사용자에게 보여주고 정확한 이름 확인 |
| 로그인 화면 | 사용자에게 Aside 브라우저에서 Google 로그인 요청 (비밀번호 입력은 하지 않음) |
| `aside` 명령 오류 | `aside --update` 후 `aside guide` 재확인 |
