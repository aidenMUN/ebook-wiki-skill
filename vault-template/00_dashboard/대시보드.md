# 📊 eBook Wiki 대시보드

> Dataview 플러그인으로 자동 집계됨 · 책을 위키화하면 바로 반영됨
> 서고 전체 권수(`library_total`)는 Claude가 `신규 확인` 때 갱신함 — 현재 `= this.library_total`권 (`= this.library_counted` 기준)

---

## 1. 전체 현황

```dataview
TABLE WITHOUT ID
  length(rows) AS "위키 반영 도서",
  round(length(rows) / this.library_total * 100, 1) + "%" AS "서고 대비 진행률",
  length(filter(rows, (r) => r.status = "검토완료")) AS "검토완료",
  length(filter(rows, (r) => r.status = "위키반영")) AS "검토 대기",
  length(unique(rows.notebook)) AS "노트북 수"
FROM "20_books"
GROUP BY true
```

```dataview
TABLE WITHOUT ID
  length(rows) AS "개념 페이지",
  length(filter(rows, (r) => length(r.sources) >= 3)) AS "근거 3권 이상 개념"
FROM "30_concepts"
GROUP BY true
```

## 2. 분야별 책 수

### 대분류 기준 (시트 B열)
```dataview
TABLE WITHOUT ID
  category AS "분야",
  length(rows) AS "책 수",
  length(filter(rows, (r) => r.status = "검토완료")) AS "검토완료"
FROM "20_books"
GROUP BY category
SORT length(rows) DESC
```

### 분야 태그 기준 (일반도서 세부 분야 포함)
```dataview
TABLE WITHOUT ID
  tag AS "분야 태그",
  length(rows) AS "책 수"
FROM "20_books"
FLATTEN file.etags AS tag
WHERE startswith(tag, "#분야/")
GROUP BY tag
SORT length(rows) DESC
```

## 3. 핵심 개념 목록

### 근거 책이 많은 개념 Top 30
```dataview
TABLE WITHOUT ID
  file.link AS "개념",
  length(sources) AS "근거 책 수",
  confidence AS "신뢰도",
  updated AS "갱신일"
FROM "30_concepts"
WHERE sources
SORT length(sources) DESC, file.name ASC
LIMIT 30
```

### 분야를 넘나드는 개념 (2개 이상 분야에서 등장)
```dataview
TABLE WITHOUT ID
  file.link AS "개념",
  unique(map(sources, (s) => s.category)) AS "등장 분야",
  length(sources) AS "근거 책 수"
FROM "30_concepts"
WHERE sources AND length(unique(map(sources, (s) => s.category))) >= 2
SORT length(unique(map(sources, (s) => s.category))) DESC, length(sources) DESC
```

### 분야별 개념
```dataview
TABLE WITHOUT ID
  cat AS "분야",
  length(rows) AS "개념 수",
  rows.file.link AS "개념"
FROM "30_concepts"
WHERE sources
FLATTEN unique(map(sources, (s) => s.category)) AS cat
WHERE cat
GROUP BY cat
SORT length(rows) DESC
```

## 4. 인물·저자·전통 Top 20
```dataview
TABLE WITHOUT ID
  file.link AS "이름",
  kind AS "종류",
  length(sources) AS "근거 책 수"
FROM "40_entities"
WHERE sources
SORT length(sources) DESC
LIMIT 20
```

## 5. 노트북별 현황
```dataview
TABLE WITHOUT ID
  notebook AS "노트북",
  length(rows) AS "책 수",
  rows.file.link AS "책"
FROM "20_books"
WHERE notebook
GROUP BY notebook
SORT length(rows) DESC
```

## 6. 최근 위키화 10권
```dataview
TABLE WITHOUT ID
  file.link AS "책",
  author AS "저자",
  category AS "분야",
  notebook AS "노트북",
  status AS "상태",
  ingested AS "위키화일"
FROM "20_books"
SORT ingested DESC
LIMIT 10
```

## 7. 점검 필요
### 근거 책이 없는 개념·인물
```dataview
LIST
FROM "30_concepts" OR "40_entities"
WHERE !sources OR length(sources) = 0
```

### 인식 품질이 낮은 책
```dataview
TABLE WITHOUT ID file.link AS "책", ocr_quality AS "인식 품질", notebook AS "노트북"
FROM "20_books"
WHERE ocr_quality AND ocr_quality != "양호"
```
