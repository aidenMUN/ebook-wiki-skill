# P02. NotebookLM 묶음 비교 프롬프트

- 사용: 이번에 위키화할 책이 **2권 이상**일 때, 해당 책들을 모두 선택한 상태로 1회 실행
- 결과는 `10_raw/<노트북폴더>/<노트북폴더>_P02_YYYYMMDD.md`로 보관되고, 개념 페이지의 "관점 차이"와 종합 페이지의 초안이 됨

```text
선택한 모든 자료를 비교해서 마크다운으로 정리해줘. 각 항목마다 어느 책의 어느 위치인지 표기해줘.

## 1. 공통 핵심 주제 5~10개와 책별 입장 (표: 주제 | 책A | 책B | …)
## 2. 저자 간 해석이나 강조점이 갈리는 지점 (각 입장의 근거 포함)
## 3. 사실관계가 서로 다르게 서술된 부분 (있으면)
## 4. 한 권에만 있는 고유한 통찰
## 5. 이 묶음을 다 읽은 사람이 던질 만한 다음 질문 5개
```
